# Code of conduct

Be kind and assume good faith. Talk about the code and the problem, not the
person. Harassment, insults and discrimination are not welcome in issues, pull
requests or anywhere else this project lives.

Powder follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

To report a problem, email hello@powder.sh. Reports are read by the maintainers
and kept confidential. A maintainer may edit or remove comments, and block people
who keep breaking these rules.
